# Archivos ignorados del proyecto

El archivo `.gitignore` permite definir los archivos y carpetas que no deben ser incluidos en el repositorio. Su configuración ayuda a mantener el proyecto organizado y evita almacenar archivos temporales, dependencias o elementos generados automáticamente durante el desarrollo.

## JavaScript y Node.js

Se ignoran las dependencias de Node.js, archivos de registro, archivos de cobertura, caché y archivos relacionados con variables de entorno.

## Sass

Se ignoran los archivos de caché y los mapas generados durante la compilación de los estilos, ya que estos pueden generarse nuevamente a partir de los archivos fuente.

## Python

Se ignoran los archivos de caché, archivos compilados y entornos virtuales generados durante la ejecución o configuración del entorno de desarrollo.

## Verificación

La configuración del archivo `.gitignore` permite mantener el repositorio limpio y evitar la inclusión de archivos que no son necesarios para el funcionamiento y desarrollo del proyecto.
