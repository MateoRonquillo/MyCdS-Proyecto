# Archivos ignorados del proyecto

El archivo `.gitignore` permite evitar que archivos innecesarios o generados automáticamente sean almacenados en el repositorio.

## JavaScript y Node.js

Se ignoran las dependencias de Node.js, archivos de registro, archivos de cobertura, caché y variables de entorno.

## Sass

Se ignoran los archivos de caché y los mapas generados durante la compilación de estilos.

## Python

Se ignoran archivos de caché, archivos compilados y entornos virtuales generados durante la ejecución.

## Verificación

Las reglas configuradas permiten mantener el repositorio limpio y evitar subir archivos que no son necesarios para el funcionamiento del proyecto.
